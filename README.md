# Electrochemistry Virtual Laboratory

A mobile-friendly Streamlit learning app based on the supplied visual reference, using a different chemistry topic: **Electrochemistry**.

## Run on a computer
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`

## Open it on your phone
To open it as a website on your phone from anywhere, deploy it to Streamlit Community Cloud:
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Sign in to https://share.streamlit.io/
3. Create an app, select the repository and `app.py`, then deploy.
4. Open the generated `.streamlit.app` link on your phone.

The app uses a centered layout and responsive CSS for smaller screens. Example data are educational and should not be treated as laboratory measurements.
